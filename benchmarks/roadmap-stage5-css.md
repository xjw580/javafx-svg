# 阶段 5：有界静态 CSS 选择器

支持原有类型、ID、class、通配符和后代选择器；新增子代 `>`、相邻兄弟 `+`、一般兄弟 `~`，以及属性存在、等值、词项、语言前缀、前缀、后缀和子串选择器。引号内空格、逗号和组合符不会被错误切开。匹配进行必要回溯，并保持源顺序与 `!important`。

特异性改为字典序（ID、class/属性、类型），不会因大量属性选择器“进位”覆盖 ID，也不会让大量 ID 覆盖内联样式。展示属性低于样式表，普通内联样式低于样式表 `!important`。

`use` 实例保留从宿主继承的属性，但复杂选择器不穿过未克隆的宿主/祖先。原有依靠 `.host .part` 穿透 use 的写法应改为宿主设置可继承属性，或在被引用子树内部声明选择器。这是规范一致性修正，不是 JavaFX 宿主 CSS 的完整 shadow-DOM 实现。

每个渲染器累计最多 2,000,000 次保守选择器工作单位（包含字符比较、祖先和兄弟扫描）；最多 128 个 compound。计数用 Long，开工前检查。超限严格模式报错，宽松模式只报告一次并停止后续样式表匹配，不再无限扫描。不会扩大已有元素/深度/资源预算。

未支持动态/功能伪类、命名空间选择器、CSS escape 和属性大小写标志；这些语法明确诊断，不声称完整 CSS。XHTML 的既有受限内联样式路径不受本项扩展为浏览器 CSS。

测试为本项目依据规范编写的语义和恶意输入回归；并非声称是捕获的第三方 SVG。
规范： https://www.w3.org/TR/selectors-3/ ， https://www.w3.org/TR/SVG/struct.html#UseStyleInheritance 。
